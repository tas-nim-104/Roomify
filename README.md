## 🚀 Project Overview
**Roomify** is a modern web application developed to streamline hotel operations and enhance the customer booking journey. It provides a centralized system for both administrators and customers.

### 🎯 Key Objectives
* Automate manual hotel management tasks.
* Reduce booking errors and administrative workload.
* Provide an easy-to-use room filtering and secure booking system.

---

## 🛠 Tech Stack
* **Backend:** Laravel 8 (PHP)
* **Frontend:** Bootstrap 5, jQuery 3, HTML5, CSS3
* **Database:** MySQL
* **Payment:** Stripe API Integration
* **Design:** Figma & Canva

---

## ✨ Features

### 💻 Customer Portal
* **Smart Filtering:** Find rooms based on dates and categories.
* **Online Booking:** Real-time availability checks and secure checkout.
* **Testimonials:** View and submit reviews (subject to admin approval).

### 🛡️ Admin Dashboard
* **Room Management:** Complete CRUD operations for rooms and types.
* **Staff Handling:** Manage staff profiles and payroll information.
* **Booking Insights:** Monitor all reservations and payment statuses.

---

## ✨ Core Features & Functionalities

### 🛡️ Admin Dashboard (Management Powerhouse)
* **Room Strategy:** Complete CRUD for Room Types (Suite, Deluxe, etc.) and individual Room Numbers.
* **Staff Operations:** Comprehensive staff database with payroll and role tracking.
* **Reservation Oversight:** Real-time monitoring of all guest bookings and payment statuses.
* **Content Management:** Dynamic control over FAQs, Gallery, Services, and Testimonial approvals.

### 💻 Customer Experience (Frontend)
* **Smart Room Discovery:** Advanced filtering based on dates, capacity, and room categories.
* **Seamless Booking:** Integrated availability engine to prevent double-booking.
* **Secure Transactions:** Fully integrated **Stripe Payment Gateway** for hassle-free checkouts.
* **User Feedback:** Interactive testimonial system for guests to share their stays.
