## 🚀 Project Overview
**Roomify** is a modern web application developed to streamline hotel operations and enhance the customer booking journey. It provides a centralized system for both administrators and customers.

### 🎯 Key Objectives
* Automate manual hotel management tasks.
* Reduce booking errors and administrative workload.
* Provide an easy-to-use room filtering and secure booking system.

---

## 🛠 Tech Stack
* **Backend:** Laravel 8 (PHP)
* **Frontend:** Bootstrap 5, jQuery 3, HTML5, CSS3
* **Database:** MySQL
* **Payment:** Stripe API Integration
* **Design:** Figma & Canva

---

## ✨ Features

### 💻 Customer Portal
* **Smart Filtering:** Find rooms based on dates and categories.
* **Online Booking:** Real-time availability checks and secure checkout.
* **Testimonials:** View and submit reviews (subject to admin approval).

### 🛡️ Admin Dashboard
* **Room Management:** Complete CRUD operations for rooms and types.
* **Staff Handling:** Manage staff profiles and payroll information.
* **Booking Insights:** Monitor all reservations and payment statuses.
